# FGO Pet

[English](README.md) | **简体中文**

FGO Pet 是面向 Windows 11 的 FGO 从者桌面伴侣。它把桌宠、专注计时、今日记录、Todo、AI 对话、记忆、Agent 任务和可选语音整合到一套本地优先的桌面体验中。

应用使用 WPF 与 .NET 8。角色图片、人格和知识以纯数据 `.fgopetpack` 单独安装，不嵌入应用程序；模型与 Agent 均为可选能力，未配置时桌宠和专注仍可离线使用。

测试范围、已知边界和反馈格式见 [v0.1.2 外部测试说明](docs/release/0.1.2-test-notes.md)。当前与下一版本计划见[路线图](docs/roadmap.md)。

## 功能概览

- **桌宠与窗口**：桌宠常驻桌面；聊天和设置是可独立切换的普通窗口，任务面板会随窗口宽度调整。
- **专注与今日**：提供预设和自定义番茄钟、暂停与恢复、当天时间线及从者羁绊进度。
- **对话与记忆**：支持多轮会话、历史恢复、角色人格与知识；候选记忆必须经过用户确认。
- **Todo 与 Agent**：Todo 在确认后才能派发；Agent 来源和项目权限默认拒绝，停止与未知结果需要真实回执或用户核对。
- **语音**：可选的语音合成、自动朗读、手动播放、停止与重试；语音不可用不会阻断其他功能。
- **数据与隐私**：提供脱敏导出、私有备份与恢复、会话删除和本地数据清理。

## ZIP 快速开始

1. 校验 ZIP 的 SHA-256 是否与发布者提供的 `SHA256SUMS` 一致。
2. 将 ZIP 完整解压到普通用户可写目录，不要直接在压缩包内运行。
3. 运行 `FgoPet.App.exe`。
4. 首次启动时导入 `.fgopetpack`，选择外观并设为当前从者。
5. 按需配置 AI 模型、Agent 或语音；这些步骤可以跳过。

角色包不能执行代码。应用会检查清单、兼容版本、路径和文件哈希。角色包与应用 ZIP 是两个独立交付物，不要将 `.fgopetpack` 放入应用压缩包内部。

## 日常使用

- 点击桌宠图标打开聊天；常用功能可从聊天和桌宠控制区进入。
- 工作窗口的侧栏提供聊天、待办、专注与设置入口；聊天历史和新对话位于聊天头部。
- 已发送消息在右侧显示，气泡随内容收窄，长文本在可用宽度内换行。
- 聊天首次打开时贴靠角色；拖动紧凑窗顶部的拖动条可调整位置，隐藏后重开会保留本次运行中的位置。角色移动不会带动聊天窗，屏幕变化后会约束到可见工作区。
- 聊天使用一体输入卡：上方编辑，下方发送／停止工具栏固定。长草稿按窗口可用空间增高，超出后内部滚动；向上阅读旧消息时保留位置。“返回底部”不遮挡正文，空上下文行不占空间。复制支持键盘操作，仅在成功后显示确认。
- 在“历史对话”中点击标题继续聊天，或确认后删除单条对话；列表显示对话标题与本地时间，每页 50 条，可通过“加载更多”查看更早的对话。生成回复期间不能删除，删除对话会保留已确认记忆。设置中的数据管理集中提供导出、备份恢复与整体清理。
- 设置按“外观与角色 / 能力 / 通用与数据”分组；能力下保留模型服务、语音朗读和 Agent 连接。用户资料页使用 WebView2，仍由原设置服务保存；其他设置页保留 WPF。返回页面时恢复各自的滚动位置。
- 系统托盘可重新显示桌宠、打开设置或退出应用。
- `Esc` 关闭当前浮层或返回上一层；主要操作支持键盘焦点与可见状态反馈。

### AI 模型

在“设置 → 能力 → 模型服务”填写 Provider、Base URL、模型和 API Key。测试连接不会保存草稿，只有显式“保存连接”才会激活新配置。API Key 保存于 Windows Credential Manager，不写入设置文件或导出。

以下上下文与记忆改动位于当前开发分支，真实模型和 Windows 实机验收仍待完成。

上下文容量按“手工覆盖 → 服务元数据 → 已知模型资料”的顺序确定；未知模型明确标注为保守估算。发送时为配置的输出上限预留空间，并计量完整提示词和工具定义；估算不等同于精确分词结果。

新对话可以检索同一角色、同一项目中的历史消息，并提供来源会话入口。历史列表默认只显示当前项目，取消筛选可打开其他项目的旧对话；未关联项目的历史单独隔离。指代不明确时会询问具体是哪件事。

长对话会整理较早的完整轮次，保留近期原文和当前待确认 Todo 草稿。原始历史不删除，压缩状态可在重启和私有备份恢复后继续使用；关闭长期记忆也不影响压缩。无法安全缩减到预算内时保留输入并说明问题。

摘要生成使用按模型上下文窗口计算的独立预算，不受普通回复长度设置限制。原生对话可以在当前会话、角色和项目范围内检索并重读已压缩原文，找回摘要遗漏的细节。摘要仍是有损整理；保留原文不代表每次模型请求都包含所有细节。

原生对话可以按需读取当前系统时间，并复用同一会话、角色和项目中仍可用的工具证据。较长的工具历史沿用现有有界压缩与保留规则，不是无限归档。每次发送最多使用 32 次模型请求和 64 次工具调用，摘要工作也计入，并预留最终回答机会。浏览器访问默认关闭，需明确的本机授权和 Chrome 连接批准；[Chrome 集成指南](tools/integrations/chrome-browser/README.md)说明读取与打开范围。生产环境未启用应用窗口发现。

长期记忆候选显示来源与适用范围，确认后才用于后续请求。角色通用偏好可跨项目召回，项目记忆只在对应项目使用。更正必须选定具体条目和版本；编辑、停用、删除会在后续请求中生效。删除来源会话保留已确认记忆，并标明来源不可用。每个角色最多保存 200 条、40,000 字符的已确认记忆，停用条目也计入；不会为腾空间自动删除旧数据。预算、压缩和记忆机制参考的固定 MIT 上游见[第三方声明](THIRD-PARTY-NOTICES.md)。

### 理解复核（开发分支）

“设置 → 持续理解”将已保存、待批准和已归档的理解分开。自动理解需要为当前角色、项目和模型接收方明确启用，从新内容开始整理。Proposals 模式生成待确认候选；Bounded 模式允许通过独立校验的低影响理解暂定生效。读取、外部处理、保存和用于回复分别授权。日额度默认 12 次后台派发，可调整、跨角色和项目共享，分类与重试分别计数；代理内部重试可能增加上游调用。前台聊天优先。纠正不会批准候选；忘掉会删除本条及历史，原始消息保留。打开页面不会触发模型请求或增加权限。

### 本机场景工具（开发分支）

原生对话可以通过 `todo.get` 查看完整待办详情，通过 `focus.resume` 恢复指定的暂停专注会话，沿用原有业务拥有者。仅 `focus.resume`、`reminder.create` 和 `reminder.cancel` 接入逐次原生确认（默认拒绝），其他原生命令工具仍保持拒绝。

一次性本地提醒需确认准确正文、日期时间和时区。提醒跨重启保存，在应用运行时通过 Windows 托盘通知；下次启动只补发逾期不超过 24 小时的提醒，更早的标为过期，不在应用关闭时后台触发。已提交通知、失败和结果未知分别记录，未知结果不自动重试。删除来源对话会清除其提醒，恢复备份不会重新启用历史提醒。

使用图片理解时，在聊天输入区选择、粘贴或拖入一张本地 PNG/JPEG，再点击发送；仅选择不会发送。支持界面披露的官方 DeepSeek `deepseek-flash`、OpenAI `gpt-4.1-mini`，以及精确的本机 Buddy 订阅路由（`custom-openai-compatible`、`http://127.0.0.1:8326/v1`、`buddy/deepseek-v4.1-flash`），后者转发至腾讯 CodeBuddy CN；其他路由仍禁用。Buddy 可能将附件落盘或重新编码，也可能重试或换号，应用没有共享的上游请求次数上限。停止或超时无法撤回已经发送的图片。在 FGO Pet 内，选择会过期，并在取消、会话范围或模型改变时清除，图片字节不写入历史或检查点。聊天菜单另有默认关闭的“网页读图权限”：开启后，模型可在读过网页文字后按需获取一个页面元素或当前可视区域，每个任务最多一张。这不授予桌面截图或后台文件读取能力，低细节图片不提供 OCR 准确率承诺；原生粘贴及生产聊天界面到代理服务的效果仍需与自动化协议、隔离 WebView2 拖拽测试分开验收。

### Agent

纯文本 QQ 私聊入口现为开发预览，位于“设置 → 服务 → QQ”，默认关闭。它将一个本机配对的 QQ 账号关联到一个已有桌面对话。尚未发送的桌面选图只属于桌面发送，动作审批仍须在桌面完成；在桌面完成追问或审批后，最终回答不会自动回传 QQ。真实 QQ 账号和 Windows 界面验收仍待完成，详见 [QQ 模块指南](plugins/FgoPet.Plugin.Qq/README.md)。

在“设置 → 能力 → Agent 连接”检测并批准真实来源，选择允许访问的项目并再次确认权限。未批准来源或项目时不能派发任务；撤销权限立即生效。应用不会把“已请求停止”冒充“已停止”，也不会自动重试结果未知的派发。

### 语音

Live2D 角色支持视线跟随、头部悬停轻反应、聊天思考、短情绪动作、闲置入睡与点击唤醒，以及随播放音量变化的口型。
等待聊天回答时侧转抬眼；开始文本回答时回正、点头一次并保持闭嘴表情，完成或取消后平滑收束。仅有文本时不驱动口型。
模型与动作通过独立角色包提供，具体反应取决于角色包素材。

在“设置 → 能力 → 语音朗读”选择并测试语音服务。语音播放支持停止、重试和长文本分段；临时音频按播放生命周期清理。

## 安全与隐私边界

- API Key 保存在 Windows Credential Manager。
- Relay/Adapter 配对凭据使用受保护的本机状态，不进入用户备份。
- Agent 协议不传输完整 Prompt、推理、工具参数、终端输出、凭据或不必要的本机路径。
- Todo 派发、记忆确认、项目授权和不可恢复的数据操作都需要明确用户动作。
- 脱敏导出不等同于完整备份；私有备份不包含凭据、角色包资产或 Agent 配对状态。
- 私有备份恢复会先校验并暂存副本，然后关闭应用；重新打开时，在常规服务启动前执行恢复。恢复失败会回滚，无法确认回滚成功时停止启动并保留恢复材料。
- FGO 美术、Atlas、音频和提取资源不存储在本仓库中。
