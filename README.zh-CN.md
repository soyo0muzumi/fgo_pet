# FGO Pet

[English](README.md) | **简体中文**

FGO Pet 是面向 Windows 11 的 FGO 从者桌面伴侣。它把桌宠、专注计时、今日记录、Todo、AI 对话、记忆、Agent 任务和可选语音整合到一套本地优先的桌面体验中。

应用使用 WPF 与 .NET 8。角色图片、人格和知识以纯数据 `.fgopetpack` 单独安装，不嵌入应用程序；模型与 Agent 均为可选能力，未配置时桌宠和专注仍可离线使用。

## 功能概览

- **桌宠与窗口**：桌宠常驻桌面；聊天和设置是可独立切换的普通窗口，任务面板会随窗口宽度调整。
- **专注与今日**：提供预设和自定义番茄钟、暂停与恢复、当天时间线及从者羁绊进度。
- **对话与记忆**：支持多轮会话、历史恢复、角色人格与知识；候选记忆必须经过用户确认。
- **Todo 与 Agent**：Todo 在确认后才能派发；Agent 来源和项目权限默认拒绝，停止与未知结果需要真实回执或用户核对。
- **语音**：可选的语音合成、自动朗读、手动播放、停止与重试；语音不可用不会阻断其他功能。
- **数据与隐私**：提供脱敏导出、私有备份与恢复、会话删除和本地数据清理。

## ZIP 快速开始

1. 校验 ZIP 的 SHA-256 是否与发布者提供的 `SHA256SUMS` 一致。
2. 将 ZIP 完整解压到普通用户可写目录，不要直接在压缩包内运行。
3. 运行 `FgoPet.App.exe`。
4. 首次启动时导入 `.fgopetpack`，选择外观并设为当前从者。
5. 按需配置 AI 模型、Agent 或语音；这些步骤可以跳过。

角色包不能执行代码。应用会检查清单、兼容版本、路径和文件哈希。角色包与应用 ZIP 是两个独立交付物，不要将 `.fgopetpack` 放入应用压缩包内部。

## 日常使用

- 点击桌宠图标打开聊天；常用功能可从聊天和桌宠控制区进入。
- 工作窗口的侧栏提供聊天、待办、专注与设置入口；聊天历史和新对话位于聊天头部。
- 在“历史对话”中点击标题继续聊天，或确认后删除单条对话；列表显示对话标题与本地时间。生成回复期间不能删除，删除对话会保留已确认记忆。设置中的数据管理集中提供导出、备份恢复与整体清理。
- 设置按“外观与角色 / 能力 / 通用与数据”分组；能力下保留模型服务、语音朗读和 Agent 连接，返回页面时恢复各自的滚动位置。
- 系统托盘可重新显示桌宠、打开设置或退出应用。
- `Esc` 关闭当前浮层或返回上一层；主要操作支持键盘焦点与可见状态反馈。

### AI 模型

在“设置 → 能力 → 模型服务”填写 Provider、Base URL、模型和 API Key。测试连接不会保存草稿，只有显式“保存连接”才会激活新配置。API Key 保存于 Windows Credential Manager，不写入设置文件或导出。

### Agent

在“设置 → 能力 → Agent 连接”检测并批准真实来源，选择允许访问的项目并再次确认权限。未批准来源或项目时不能派发任务；撤销权限立即生效。应用不会把“已请求停止”冒充“已停止”，也不会自动重试结果未知的派发。

### 语音

在“设置 → 能力 → 语音朗读”选择并测试语音服务。语音播放支持停止、重试和长文本分段；临时音频按播放生命周期清理。

## 安全与隐私边界

- API Key 保存在 Windows Credential Manager。
- Relay/Adapter 配对凭据使用受保护的本机状态，不进入用户备份。
- Agent 协议不传输完整 Prompt、推理、工具参数、终端输出、凭据或不必要的本机路径。
- Todo 派发、记忆确认、项目授权和不可恢复的数据操作都需要明确用户动作。
- 脱敏导出不等同于完整备份；私有备份不包含凭据、角色包资产或 Agent 配对状态。
- FGO 美术、Atlas、音频和提取资源不存储在本仓库中。
