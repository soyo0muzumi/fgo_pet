# FGO Pet 桌宠设计规格

日期：2026-08-25

状态：已批准

首发平台：Windows

首发从者：玛修·基列莱特

## 1. 产品定位

FGO Pet 是一款以角色陪伴和工作/学习辅助同等重要的 Windows 本地桌宠。所有效率功能均通过从者身份呈现，而不是在普通效率工具上覆盖角色皮肤。

首版服务个人本地使用，但程序、资源、模型和 Agent 接口必须为后续可分发版本保留清晰边界。产品以日常陪伴为主线，不设计复杂养成、虚拟经济或项目管理系统。

核心分工：

- Codex 等 Agent 负责拆解、安排和执行任务。
- 桌宠负责展示关键进度、提醒用户介入、记录成果并提供角色化情绪反馈。
- 番茄钟独立于 Agent 任务，向统一事件系统提供专注状态。
- 对话模型负责交流和重要节点反馈，不获得任务、工具或系统控制权。

## 2. 范围

### 2.1 首版包含

- 透明、无边框、可置顶的静态立绘桌宠。
- 拖拽、缩放、表情切换、单击聊天和右键菜单。
- 玛修的灵基与服装自由选择。
- 十类表情：默认、微笑、担心、惊讶、生气、疲惫、认真、害羞、庆祝、安慰。
- 跟随玛修移动的常驻番茄钟。
- OpenAI 兼容文本对话接口。
- 本地聊天历史和可管理的摘要式长期记忆。
- 全部已公开剧情支持的人格塑造与按需知识检索。
- Codex 插件推送的关键任务事件。
- 以今日时间线为核心的进度记录。
- 轻量羁绊、特殊对话和礼装收藏。
- 经授权的本地应用类别感知。
- 半自动素材整理工具和可移植从者资源包。
- 本地备份、恢复与数据迁移。

### 2.2 首版不包含

- 语音输入、语音合成或实时语音对话。
- 骨骼动画、Live2D 或战斗小人动画。
- 完整项目管理、看板、甘特图或 Agent 执行日志。
- 等级、体力、货币、商店、抽取或装备属性。
- 聊天模型执行工具、修改任务或控制系统。
- 读取窗口标题、屏幕、文档内容或键盘输入。
- macOS/Linux 支持。

## 3. 用户使用流程

1. 应用随 Windows 启动后，玛修出现在上次位置，并恢复所选灵基、服装和缩放。
2. 玛修旁常驻紧凑番茄钟。用户可以选择预设，或设置工作时间、休息时间和循环轮数。
3. 单击玛修打开或收起聊天。首次使用时，用户只需配置 API 地址、API Key 和模型名称。
4. Codex 任务默认同步关键事件。玛修通过表情和短气泡反馈，有回顾价值的事件进入今日时间线。
5. Codex 等待用户处理时，气泡持续显示并保留未处理标记；点击后跳转到对应 Codex 任务或可用的替代入口。
6. 番茄钟开始、完成或中断时，玛修改变表情并给出本地反馈；重要节点才调用 LLM。
7. 完成任务和有效专注积累少量羁绊。关键节点触发特殊对话并解锁礼装收藏。
8. 右键菜单提供从者与外观、今日记录、设置、隐藏和退出。
9. 应用感知首次启用时询问权限，且可以随时关闭。

## 4. 技术路线与验证门槛

首选技术路线：

- 主程序：C#、.NET 8、WPF。
- 立绘渲染：在技术验证中比较 WPF Image 与 SkiaSharp。
- 素材整理：Python。
- 本地数据：SQLite。
- 密钥：Windows 凭据管理器。
- LLM：OpenAI 兼容接口。
- Codex 集成：Codex 插件、Skill、MCP 工具和本地事件桥。

正式桌宠工程开始前必须完成内容准备与一次性渲染验证：

- 使用玛修透明立绘测试 100%、125% 和 150% Windows 缩放。
- 测试多显示器、跨屏拖拽、运行时缩放和气泡附着。
- 比较 WPF Image 与 SkiaSharp 的透明边缘、清晰度、内存和响应速度。
- 验收标准为边缘无明显模糊或黑边、坐标稳定、跨屏后清晰度不退化、拖拽与表情切换无明显闪烁。
- 验证工程属于可丢弃实验，不直接演变为正式项目。

## 5. 架构与模块边界

### 5.1 桌宠显示层

负责透明立绘、表情切换、拖拽、缩放、气泡、菜单和点击区域。显示层只消费状态，不直接访问 LLM、Codex 或数据库。

### 5.2 番茄钟

维护独立计时状态，窗口附着于玛修并跟随移动。产生开始、暂停、继续、完成、中断、休息开始和休息完成事件。

### 5.3 事件中心

统一接收番茄钟、Codex、时间段、应用类别、成就和系统异常事件，负责校验、优先级、去重、合并和冷却。

### 5.4 角色反馈引擎

根据事件选择表情、气泡和台词。普通事件使用本地资源；重要节点可以调用 LLM。LLM 不可用时必须立即回退。

### 5.5 对话与 Prompt 编排

处理聊天、流式回复、结构化输出校验、上下文选择和错误回退。Prompt 由系统自动生成，用户不编辑提示词。

### 5.6 记忆与剧情知识

长期记忆采用候选、确认和删除状态。剧情知识以主题条目和本地检索索引提供，仅在相关对话中注入。

### 5.7 Codex 适配器

通过可安装插件主动推送统一任务事件，不读取 Codex 私有数据库，不抓取终端日志。

### 5.8 时间线、羁绊与收藏

保存有回顾价值的事件和结算结果。羁绊只由真实完成产生；礼装仅作为纪念收藏。

### 5.9 应用感知

在获得授权后读取当前应用名称或类别，只在本地转换为抽象事件，不保存原始切换历史，不上传至 LLM。

### 5.10 资源包系统

程序核心不包含从者特例。资源包声明外观、表情、台词、人设、知识和礼装，并可独立导入、校验与升级。

## 6. 统一事件模型

所有来源必须先转换为统一事件，再影响表情、气泡、时间线或羁绊。

事件基础字段：

- `event_id`：全局唯一标识。
- `source`：`codex`、`pomodoro`、`system`、`app_context`、`bond` 或 `dialogue`。
- `type`：事件类型。
- `occurred_at`：带时区的发生时间。
- `priority`：P0 至 P4。
- `summary`：面向用户的短摘要。
- `subject_id`：可选的任务或会话标识。
- `private`：是否按敏感事件处理。
- `payload`：经过来源适配器清理的结构化附加信息。

优先级规则：

| 优先级 | 典型事件 | 表情倾向 | 气泡行为 |
|---|---|---|---|
| P0 | Codex 等待用户、关键配置失效、资源包损坏 | 认真、担心 | 持续显示并保留标记 |
| P1 | 任务完成/失败、番茄循环完成、成就解锁 | 庆祝、安慰、担心 | 较长显示并写入时间线 |
| P2 | 任务开始、里程碑、番茄开始/中断、恢复活动 | 认真、微笑、疲惫 | 短气泡并写入时间线 |
| P3 | 时间段、应用类别、长时间空闲 | 默认、微笑、认真 | 满足冷却后才显示 |
| P4 | 点击、拖拽、切换服装 | 害羞、惊讶、微笑 | 本地短台词，不写时间线 |

冲突规则：

- 高优先级事件可打断低优先级反馈。
- P0 在问题解除前不被普通事件覆盖；气泡可收起，未处理标记不可提前清除。
- 专注期间抑制 P3 与 P4。
- 同类事件在短时间窗口内合并。
- 表情结束后回到上下文表情：专注为认真，连续工作过久或深夜为疲惫，其余为默认。
- 本地台词执行近期去重。

## 7. Codex 集成

### 7.1 部署形态

个人版使用本地个人插件；后续分发版发布为可安装 Codex 插件。插件包括：

- FGO Pet Skill：规定哪些节点需要汇报，以及摘要和隐私规则。
- MCP 工具：以结构化方式向本地事件桥发送事件。
- 协议版本声明：允许桌宠与插件独立升级并协商兼容版本。

桌宠本体未安装插件时仍可正常使用其他功能。

### 7.2 任务事件

- `task_started`
- `milestone_reached`
- `user_attention_required`
- `task_resumed`
- `task_completed`
- `task_failed`
- `task_cancelled`

Codex 事件只包含任务标识、标题、状态、时间、用户可读摘要、成果入口和隐私标记。命令、工具调用、完整推理和终端输出不得进入桌宠数据库。

### 7.3 同步规则

- 默认同步所有 Codex 任务。
- 用户可按任务、项目、目录或关键词关闭同步。
- 敏感事件只显示匿名状态，不保存标题和摘要。
- 事件使用任务标识和序号去重。
- 断开时在发送端持久化排队；重连后顺序补发。
- Codex 恢复工作后清除等待用户标记。
- 跳转优先打开 Codex 任务；若外部跳转能力不可用，则打开成果文件或复制任务标识。

## 8. 对话、Prompt 与知识

### 8.1 人格

玛修保持角色人格和对用户的默认称呼“前辈”，同时理解自己作为电脑桌面中的陪伴者，可以自然讨论文件、Agent、任务和专注时间。

允许使用全部已公开剧情塑造人格和关系理解，但不主动复述剧情。只有用户主动询问相关人物或剧情时，才检索剧情知识。

### 8.2 Prompt 分层

1. 核心人设：性格、价值观、称呼、语言习惯和混合身份。
2. 行为规则：日常、简短、自然，不虚构任务状态，不获得系统控制权。
3. 动态上下文：时间、番茄状态、必要任务摘要、近期成果和相关长期记忆。
4. 按需知识：与当前问题相关的剧情资料片段。

用户只配置 API 地址、API Key 和模型名称。系统不向用户暴露 Prompt 编辑功能。

### 8.3 模型输出

```json
{
  "text": "辛苦了，前辈。先稍微休息一下吧。",
  "emotion": "comfort",
  "feedback_type": "encouragement",
  "memory_candidate": null
}
```

- `emotion` 必须是当前资源包支持的受限标签。
- `feedback_type` 只影响展示和统计，不触发系统操作。
- `memory_candidate` 只能进入候选队列，不直接成为事实。
- 格式异常时保留可提取正文，并回退到默认表情。
- 普通对话支持流式显示正文。

### 8.4 长期记忆

- 聊天历史存于本地。
- 从对话中提炼用户偏好、长期目标、重要经历和称呼习惯。
- 候选记忆必须可查看、编辑、禁用和删除。
- 每次请求只注入与当前对话相关的记忆。
- 不把所有聊天历史长期塞入模型上下文。

### 8.5 剧情资料处理

- 将原始剧情整理为主题条目，而不是直接把整章文本塞入上下文。
- 条目至少包含主题、人物、关系、时间阶段、摘要、关键词和来源定位。
- 在本地建立可重建的检索索引。
- 检索结果只用于当前请求，不自动写入长期记忆。

### 8.6 已验证的玛修知识标准

本标准由 `docs/reports/2026-08-26-mash-phase0-readiness.json` 的 PASS 结果约束：

- lore 资料卡的紧凑摘要常驻；逐章解锁的长篇评论不常驻，具体剧情按问题检索。
- 官方中文逐字段优先；中文缺失时回退日文，并保留 `source_region`、`source_path`、原文与 `jp_fallback`。
- 明确剧情问题使用本地 SQLite FTS5；中文连续短语优先，已验证别名参与召回，可选重排器失效时回退 FTS。
- 每次只注入 2–4 个场景窗口，总预算不超过 900 tokens；单一命中展开同脚本相邻场景。
- 默认先用 2–4 句直接回答，用户要求时再展开下一轮检索。有证据时不得笼统回答“不清楚”；证据不足时说明资料覆盖范围，不把资料缺口写成角色失忆。
- 运行时保留 `answered_from_profile`、`answered_from_story` 与 `coverage_gap` 状态及内部来源定位，但不向用户泄漏本地路径或完整 Prompt。

## 9. 桌宠交互与番茄钟

### 9.1 桌宠窗口

- 透明、无边框、可置顶。
- 拖拽移动；计时器和气泡作为附着窗口同步移动。
- 单击打开或收起聊天。
- 右键进入从者与外观、记录、设置、隐藏和退出。
- 系统托盘提供恢复、设置和退出的备用入口。
- 多显示器布局改变时自动回到可见工作区。

### 9.2 系统事件反馈

- 系统事件只显示表情和短气泡，不加入聊天记录。
- 详情进入今日时间线。
- Codex 等待用户时，气泡持续到点击或状态解除，并保留未处理标记。
- Windows 系统通知由 Codex 自身负责，桌宠不重复发送。

### 9.3 番茄钟

- 用户自由设置工作时间、休息时间和循环轮数。
- 支持多个预设。
- 常驻紧凑控件提供开始、暂停/继续和停止。
- 状态为 `idle`、`focus`、`paused`、`break`、`completed`。
- 事件为 `focus_started`、`focus_paused`、`focus_resumed`、`focus_completed`、`focus_stopped`、`break_started`、`break_completed` 和 `cycle_completed`。
- 只有自然完成的工作阶段计入有效专注。
- 暂停不结算；中断与失败不扣除任何数值。
- 程序重启后根据持久化时间戳恢复并判断真实状态。
- 常规开始/结束使用本地台词，完整循环、连续完成和异常中断等重要节点可以调用 LLM。

## 10. 今日时间线、羁绊与收藏

### 10.1 今日时间线

- 默认显示当天，可切换历史日期。
- 显示时间、来源、标题、状态、摘要、隐私标记和可选跳转入口。
- 页面顶部显示完成数、有效专注时长和羁绊变化。
- 相邻重复事件合并。
- 不保存原始应用切换日志或 Agent 完整过程。

### 10.2 羁绊

- 使用单一累计值，不设计等级、货币或商店。
- 主要来源为 Codex 任务完成、有效番茄钟和阶段性成果。
- 普通聊天、点击、重复启动和无效中断不增加羁绊。
- 失败、取消、中断和休息不扣除羁绊。
- 设置每日自然上限，限制无意义刷取。
- 时间线记录每次结算来源。

首版具体分值、每日上限和解锁阈值作为内容配置，不写死在业务代码中，并在阶段 2 的可用性测试中确定。

### 10.3 收藏

- 只在少量关键节点触发特殊对话和礼装解锁。
- 支持情人节礼装、羁绊礼装等玛修相关资源。
- 礼装仅用于纪念展示，无属性、货币、抽取和装备效果。

## 11. 从者资源包与素材工具

### 11.1 三层资源

- 原始素材库：Atlas API 提取结果，只读保存。
- 整理工作区：缩略图、候选分组、裁切预览和人工标注。
- 可发布资源包：只包含运行所需内容，全部使用相对路径。

### 11.2 半自动整理流程

1. 扫描指定从者目录，提取尺寸、Alpha、资源编号和 Atlas 元数据。
2. 按来源类型、外观标识和图片相似度分组。
3. 生成人工审核用缩略图索引。
4. 为每套外观选择默认立绘和最多十类表情。
5. 设置统一画布中的裁切、缩放、脚底锚点和气泡锚点。
6. 叠加比较表情，检测跳位、越界、透明边缘和过度留白。
7. 为缺失表情配置回退链。
8. 生成优化副本和资源包清单，不修改原始素材。
9. 校验文件存在性、尺寸、Alpha、哈希与清单版本。

### 11.3 资源包结构

```text
mash/
├─ manifest.json
├─ portraits/
├─ costumes/
├─ craft_essences/
├─ dialogue/
├─ persona/
└─ knowledge/
```

清单描述从者身份、包版本、外观、表情映射、锚点、裁切、缩放、回退规则和文件哈希。程序核心不得依赖 FGO 原始文件名。

每套外观独立配置表情。若某套服装只有一张合适立绘，则允许全部情绪回退到同一图片，由气泡承担表达。

### 11.4 已验证的玛修默认常服

- 默认外观 ID 为 `mash_casual_98001000`，来源图为只读的 `98001000_merged.png`。
- 当前已提供 1 个常服全身资产和 28 个表情资产；每个资产同时保留 raw 与透明 runtime 版本。
- 表情运行时键固定为 `r01c01`–`r07c04`，中文语义标签可以迭代但不得改变稳定键或文件关联。
- manifest 保存来源/输出哈希、原图裁切矩形、透明前景包围盒、底部中心锚点及相对路径。
- 自动校验、联络表和代表性裁切视觉复核均已通过；原图和生成 PNG 继续位于仓库外。

## 12. 本地数据与隐私

### 12.1 存储

- SQLite：聊天、记忆、时间线、番茄统计、羁绊和收藏。
- 普通设置：窗口位置、外观、计时预设、隐私选项和模型名称。
- Windows 凭据管理器：API Key。
- 资源包目录：立绘、人设、台词、知识和礼装。
- 可清理缓存：缩略图、响应缓存和临时事件。

### 12.2 云端边界

允许发送给用户配置的模型服务：

- 用户聊天文字。
- 必要任务摘要。
- 番茄钟状态。
- 相关长期记忆。
- 相关剧情知识片段。

禁止发送：

- 当前应用名称或类别。
- 窗口标题、屏幕、文档内容或键盘输入。
- Codex 命令、工具过程和完整日志。
- API Key 或本地路径，除非用户在聊天中主动输入。

### 12.3 应用感知

- 首次启用时明确询问。
- 读取进程对应的应用名称，并在本地映射为类别。
- 用户可关闭、重分类或排除应用。
- 原始切换记录不长期保存；只有形成有意义的抽象事件才进入时间线。

## 13. 错误处理、恢复与备份

- 数据库写入使用事务；事件唯一标识防止重复记录和结算。
- LLM 超时、断网或格式异常时立即使用本地反馈。
- Codex 插件离线时在发送端持久化排队并重连补发。
- 资源包损坏时回退到最后可用外观并进入 P0 提示。
- 番茄钟使用持久化时间戳，重启不会重复结算。
- 崩溃日志仅保存在本地，并过滤凭据、对话正文和敏感任务摘要。
- 支持导出包含数据库、设置和用户生成记忆的本地备份包。
- API Key 不进入备份。
- 从者资源包默认只记录标识和版本，需要时单独导出。
- 导入前校验版本并自动备份现有数据。
- 数据库迁移使用独立架构版本。

## 14. 测试策略

### 14.1 渲染与窗口

- 100%、125%、150% DPI 缩放。
- 单屏和多屏，包含不同缩放比例的跨屏移动。
- 透明边缘、缩放、表情切换、气泡锚点和计时器跟随。
- 点击区域、拖拽、右键菜单、置顶、托盘恢复和屏幕布局变化。

### 14.2 事件与状态

- 优先级抢占、P0 持续状态、同类合并、冷却和去重。
- 番茄钟暂停、恢复、中断、程序重启和系统时间变化。
- Codex 离线、重连、重复投递、乱序和敏感事件清理。
- 羁绊仅结算一次，且失败与中断不扣分。

### 14.3 对话与数据

- OpenAI 兼容接口的流式与非流式响应。
- 合法、缺字段、非法标签、非 JSON、超时和断网响应。
- 记忆候选、编辑、删除和相关性选择。
- 剧情索引重建和无结果回退。
- 数据库迁移、备份、恢复和资源包校验。

### 14.4 隐私

- 应用感知未授权时不读取进程信息。
- 应用信息不会进入模型请求或日志。
- 敏感项目事件匿名化。
- API Key 不出现在配置、数据库、备份和崩溃日志中。
