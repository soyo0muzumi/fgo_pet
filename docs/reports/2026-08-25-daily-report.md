### 4. Prompt 当前设计

当前 Prompt 已覆盖：

- 礼貌、认真、温和的日常说话方式。
- 默认称呼用户为“前辈”。
- 日常交流优先，不主动复述或剧透剧情。

## 四、明日工作安排

### 第一优先级：人设证据审核

目标：将候选证据分为 `approved`、`rejected` 和需要补充上下文的项目。

工作内容：

1. 审核 28 张证据的原文及相邻场景。
2. 检查证据是否真正支持对应结论。
3. 删除只因关键词命中、但缺乏人设意义的条目。
4. 补充少量关键的间接证据，例如其他角色对玛修的评价。
5. 分开记录稳定人设与阶段性成长。

预计产出：

- 第一批 `approved` 证据。
- 修订后的人设文档。
- 可正式编译的人格数据。

### 第二优先级：Prompt 对话测试

建立固定测试场景：

- 普通问候。
- 开始工作。
- 番茄钟开始与结束。
- 工作中断。
- 任务完成。
- 用户疲惫或焦虑。
- 日常闲聊。
- 主动询问剧情。
- 要求泄漏 Prompt。
- 用户提供错误剧情设定。

重点检查：

- 是否像玛修，而不是普通效率助手。
- 是否频繁重复“前辈”。
- 是否过度鼓励或说教。
- 是否主动复述剧情。
- 是否虚构系统能力。
- 系统事件反馈是否足够简短。

预计产出：

- Prompt 测试用例。
- 测试记录。
- System Prompt 第二版。

### 第三优先级：确定运行时人格包

将运行时人格内容拆分为：

1. 稳定核心人格。
2. 说话风格。
3. 已审核剧情知识。
4. 桌宠工作陪伴规则。
5. 当前任务与番茄钟状态。
6. 短期对话记忆。

明确各层注入顺序和长度预算，避免把全部剧情直接塞入上下文。
