# FGO Pet 后续开发路线

更新时间：2026-09-12

本文记录当前测试收口、后续产品方向与退出条件。路线是开发目标，不代表已实现、已验收或已获发布授权；历史计划、设计稿与详细验收证据保留为本地开发记录。

产品方向：以角色陪伴为主体，通过“能力”组织对话、语音、专注及后续情境感知和工作进度联动。功能配置易理解，日常操作仍有直接入口，离线基础工具不依赖模型。

## Now：v0.1.2 外部测试

v0.1.2 已合入本地 `main`，当前目标是生成 Windows x64 ZIP 并交给测试人员验证，不包含 MSI、自动更新或正式公开发布授权。

当前范围：

- 独立的桌宠、聊天与设置窗口，以及宽窄窗口下的任务面板。
- 对话历史、项目/意图上下文、Todo 提案和 Agent 任务状态。
- Agent 项目授权、停止确认、断线与未知结果恢复。
- Provider-neutral 语音模块、语音设置与播放生命周期。
- 模块化目录、共享 UI foundation 和对应自动化测试。

外测重点：

1. Windows 100%/150%/200% DPI、多显示器、中文 IME、键盘和高对比度。
2. 长对话、历史恢复、模型失败与重试，以及窄窗口布局。
3. 已含 Agent 的测试包保留项目授权、派发、停止、断线和恢复验证；后续普通用户入口撤下不代表历史包已停用，也不能掩盖遗留执行状态。
4. 真实 TTS 的播放、停止、长文本分段和临时文件清理。
5. 异常退出、重启、备份恢复和既有用户数据兼容性。

退出条件：每个确认缺陷都有复现步骤、严重级别和处理结论；P0/P1 无未解决回归；候选 ZIP 可重复生成并通过 manifest、哈希与隔离验收。

## Next A：稳定性收口

v0.1.3 仍暂定为外测反馈收口版本，不把下述全部视觉与能力建设强行纳入同一版本。后续版本号与交付日期在范围冻结时确定。

### P0

- 修复导致崩溃、数据丢失、凭据泄露、越权、任务错误重放或主流程不可用的问题。
- 建立外测问题模板，记录版本、系统、复现步骤、日志范围和隐私清理要求。
- 为确认回归补充自动化测试，并重新执行完整 Release 门禁。

### P1

- 修复设置进入角色包后无法返回外观与角色的问题，覆盖列表、详情和重复点击一级栏目。
- 改善模型和语音失败时的可理解状态；保留旧 Agent 执行所需的最小恢复入口。
- 完善对话、任务、专注和窗口状态在异常退出后的恢复一致性。
- 收敛 DPI、IME、键盘、Narrator/高对比度和多显示器问题。
- 形成可公开维护的发布说明、支持矩阵和已知限制。

### 发布准备

- 决定是否恢复 MSI、签名和安装器生命周期验证。
- 明确升级、回滚和用户数据保留策略。
- 形成可公开维护的发布说明、支持矩阵和已知限制。
- 在获得明确授权后再创建标签、上传附件或公开 Release。

退出条件：外测阻塞问题关闭；全量构建与测试通过；目标 Windows 环境人工检查有证据；发布包版本、Changelog、支持矩阵和哈希一致。

## Next B：能力设置与视觉整合

目标：沿用现有窗口与业务服务，将设置整理为“外观与角色 / 能力 / 通用与数据”，优先改善设置和聊天的观感与操作层级。

- 能力首页先承接现有对话、语音和专注配置，状态来自真实服务；不展示未开放能力占位。
- 保留桌宠点击收起/展开、悬停说明及拖动交互，统一按钮与状态外观。
- 采用柔和紫色、清晰文字与角色构图，先确认真实尺寸的设置与聊天设计，再统一主题、控件和其他页面。
- 优化轻量待办快速添加、完成与返回体验；不顺带扩展独立子任务、标签或复杂项目管理。
- 原 Agent 实现保留、冻结扩展，普通入口与自动启动/重连/后台活动分别收口；兼容已有活动和未知结果记录，不删除数据、不冒充完成。
- 保留深色主题和旧配置；不以视觉简化改变密钥、角色包、备份恢复与授权边界。

退出条件：一级栏目、子页返回与旧配置深链可用；设置和 Chat 在默认/最小窗口及浅/深色下通过用户视觉确认；DPI、IME、键盘和无障碍有实机证据；Agent 普通模式停用与历史恢复分别验证；适用自动化检查通过且无新增阻塞回归。

## Next C：主动陪伴最小版本

目标：让角色对用户行为和日常时间作出适度、连续的回应。

- 复用既有专注事件、角色反馈与表情链路，加入可控触发、冷却、去重和免打扰。
- 先使用本地时间与应用内确认事件，验证一个角色的小规模日常互动和短篇连续故事。
- 点击展开交互，忽略不惩罚；不抢焦点，不补发离线期间积压事件。
- 先从已有 Todo 与专注记录形成可编辑的工作学习回顾，区分计划、实际完成与模型建议。
- 故事持久化、包格式扩展、备份清除与旧包兼容在实现前明确；本阶段不默认读取其他应用内容。

退出条件：真实试用确认频率与角色语气；重复通知、重启、睡眠、时钟变化、切换角色、缺素材和写入失败不造成重复推进或数据错误；基础功能在模型不可用时继续运行。

## 后续验证方向

- 情境感知：逐项评估指定应用运行/前台状态和游戏适配，按数据范围单独授权；不推断应用打开即为学习成果。
- 工作进度联动：原 Agent 可能作为真实状态接收的技术基础；开放前重新验证权限、状态与恢复，不默认增加执行能力。
- Live2D：独立进行单角色美术与渲染样板，验证交互、DPI、性能和静态回退，不阻塞基础 UI 与事件版本。
- 角色与灵衣：复用纯数据角色包，先完善单角色表情、日常反馈与故事，再扩展角色数量。

## Later：尚无版本承诺

- 自动更新。
- 角色包签名和可信来源机制。
- 更多语言与跨平台支持。
- 文件管理、浏览器/家庭设备控制和更复杂的 Agent 工作流编排；“能力”栏目不代表这些功能已经开放。
- 更多正式角色包及审核流程。
