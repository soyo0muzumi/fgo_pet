## Next：首版发布后的稳定性工作

这些项目在 `0.1.0` 发布并收集真实使用反馈后再排期：

- `0.1.1` 历史对话查看：会话列表、打开会话、加载消息，以及重启后的最近会话恢复。
- Todo/LLM 输出可靠性：复现结构化输出无法正常派发的问题，重新评估严格模板、tool call 或 MCP 边界；不纳入当前 `0.1.0` 收尾改动。
- 崩溃日志和诊断导出。
- 安装器修复、升级和回滚体验。
- Agent 任务历史、筛选和异常恢复体验。
- 更多正式角色包和角色包审核流程。

- 用户如何安装和使用：写入 `docs/guides/`。
- 当前发布条件和已知限制：写入 `docs/release/`。
- 当前未完成事项：写入本文。
- 重大架构决策：保留在 `docs/decisions/`，但必须标记 Accepted、Superseded 或 Historical。
- 具体实施步骤、交接记录和一次性验收输出：作为内部开发记录保存，不作为远程文档导航入口。
- 已完成事项不得继续以未完成 checklist 的形式出现在当前路线图中。
