# FGO Pet v0.1.2 外部测试说明

这是面向测试人员的 Windows x64 ZIP 测试版本，不是正式公开发布。它需要 Windows 11 和 .NET 8 Desktop Runtime，不包含 MSI、签名或自动更新。

## 运行

1. 校验下载文件的 SHA-256 与随包 `SHA256SUMS` 一致。
2. 将 ZIP 完整解压到普通用户可写目录，不要直接在压缩包内运行。
3. 运行 `FgoPet.App.exe`。模型、Agent 和语音均为可选配置；未配置时离线桌宠和专注功能应继续可用。
4. 测试数据请使用可丢弃的配置或备份，不要在反馈中附带 API Key、完整对话、Prompt、终端输出或私人路径。

## 重点测试

- 首次启动、角色包选择、退出和重启恢复。
- 桌宠、聊天、设置和任务面板的窗口关系；100%/150%/200% DPI、不同窗口宽度、中文 IME 和键盘操作。
- 长对话、历史切换、错误提示、重试和草稿保留。
- Todo 提案确认、Agent 项目授权、派发、停止、断线和未知结果恢复。
- 语音配置、短/长文本播放、停止、重试和退出清理。
- 睡眠/唤醒、异常退出、备份恢复及既有数据兼容性。

## 反馈格式

- 严重级别：P0 崩溃/数据或安全问题；P1 主流程不可用；P2 明显体验问题；P3 建议。
- 环境：Windows 版本、缩放率、显示器数量、.NET Desktop Runtime 版本。
- 版本：v0.1.2，以及 ZIP 文件 SHA-256。
- 复现：前置条件、逐步操作、预期结果、实际结果、是否稳定复现。
- 证据：经过脱敏的截图或最小日志片段；不得包含密钥、完整对话或私人路径。

如遇疑似数据丢失、凭据暴露、越权、任务重复执行或无法退出，请停止继续使用该数据副本并按 P0 报告。
