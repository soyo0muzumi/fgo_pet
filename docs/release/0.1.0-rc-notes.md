# FGO Pet 0.1.0 Release Candidate

## 状态

这是 Windows x64 本地正式候选，不是正式公开发行版本。GUI MSI、Mash 角色包和证据索引已经生成；安装、启动、升级数据保留和 Windows Installed apps 卸载已由用户验收通过，仍需最终发布授权。

## 已包含

- Windows x64 `.NET 8` WPF 桌宠与附着面板。
- 独立 `.fgopetpack` 角色包安装、校验和外观选择。
- 专注计时、今日记录、羁绊、Todo、对话与记忆功能。
- 可选的 Codex Agent Relay/Adapter 集成。
- 私有备份与恢复、数据导出和隐私控制。
- WiX 5.0.2 per-user GUI MSI 安装器。
- Mash 1.0.0 独立角色包，包含 28 个表情素材和 Phase 3 八个核心语义映射。

## 已验证

- Release 构建和候选包完整性校验通过。
- 独立 acceptance gate 通过：解压、可执行文件、MCP smoke、重复安装升级和卸载保留隔离状态。
- 当前环境下角色激活、专注启动/暂停/继续/停止/完成、DPI 和长时间运行回归通过。
- 多显示器和角色包升级在当前硬件/候选条件下标记为 N/A。
- 角色包 dry-run/build 和 WiX MSI 构建通过；证据索引位于 `docs/internal/release-evidence/0.1.0/`。

## 当前限制

- 候选包是 framework-dependent Windows x64 ZIP，需要 `.NET 8 Desktop Runtime`。
- MSI 的实际安装、启动、覆盖安装/升级数据保留和卸载后用户数据保留已通过用户验收。
- 应用与角色包是分开的 artifact；没有角色包时不会进入空白桌宠状态。
- AI 模型和 Agent 连接需要单独配置，离线桌宠和专注功能不依赖它们。
- 当前“对话”面板只显示当前会话；历史会话查看和重启后的会话恢复计划放入 `0.1.1`。

## 后续版本

语音和文件管理不属于 `0.1.0`，后续版本排期前需要分别定义模块边界、权限、失败降级和验收标准。
